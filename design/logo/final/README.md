# 浮现 Fuxian Logo

正式标志由三页展开的书纸与繁体「見」融合而成。三页纸同时形成近似「王」的轮廓，表达 Markdown 内容从源文件中展开，并以完成态文档被看见。项目默认使用带圆角承载面的应用 Logo；裸标用于单色印刷、反白和水印等场景。

## 设计规范

- 仅使用中性灰阶，不添加投影、浮雕或局部高光。
- 标志内部固定使用繁体「見」，不可替换为简体「见」。
- 不改变书页与字形的相对比例、间距和连接关系。
- 最小界面尺寸为 `24px`；`16px` 仅用于 favicon 等受限场景。
- 应用 Logo 的灰白承载面从 `#FCFDFD` 平滑过渡至 `#E7EAEC`，石墨图形从 `#4A4D50` 平滑过渡至 `#2F3337`；两个平面采用一致的左上至右下方向。
- 圆角承载面四周保留 `4%` 的透明净空，裸标四周保留至少标志宽度 `8%` 的净空。

## 文件

| 文件                                  | 用途                              |
| ------------------------------------- | --------------------------------- |
| `fuxian-app-icon.svg`                 | 默认圆角矩形应用 Logo             |
| `app-icon/fuxian-app-icon-{size}.png` | `16` 至 `1024px` 的应用 Logo 导出 |
| `flat/fuxian-app-icon-flat.svg`       | 可直接回滚的纯平版矢量归档        |
| `fuxian-mark.svg`                     | 裸标矢量母版，使用 `currentColor` |
| `png/fuxian-mark-{size}.png`          | `16` 至 `1024px` 的透明底裸标导出 |
| `fuxian-mark-source.png`              | 定稿位图源文件，保留用于回溯      |

Electron 应用图标位于 `apps/desktop/resources/icon.png`，与默认应用 Logo 保持一致。
