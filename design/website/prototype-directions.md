# Website Prototype Directions

These concepts were generated with Codex's built-in image generation tool. They are composition studies rather than production assets. Generated interface text and logos must not replace the repository's official assets.

## A: Editorial publication

File: `homepage-concept-a-editorial.png`

```text
Use case: ui-mockup
Asset type: high-fidelity desktop website prototype, concept A
Primary request: Create a distinctive Chinese landing page for 浮现, a Markdown desktop reader. Direction A is a contemporary independent publishing house: editorial, typographic, confident, unusually refined. The product must feel like a finished-document reader, not developer tooling.
Input images: Image 1 is the official Fuxian mark and must remain visually recognizable; Image 2 is the real application UI and must be the dominant product evidence.
Composition/framing: 16:9 full website screenshot at desktop scale. A slim brand header. Large but controlled headline “让 Markdown 值得阅读” aligned to a strong editorial grid. The real app screenshot spans most of the width below the headline, cropped sharply enough to inspect. Add a visible hint of a second section at the bottom with one oversized pull quote and small capability index labels. Use fine rules, margin notes, section numbering, and one bold blue typographic accent.
Style/medium: high-end Swiss editorial design mixed with modern technical publication, HTML/CSS-realistic, precise baseline grid
Color palette: white, graphite, cool gray, vivid cobalt blue, tiny muted red detail
Text (verbatim): “浮现”, “让 Markdown 值得阅读”, “打开一份文档”, “免费下载”, “Windows · macOS”
Constraints: actual product first, crisp Chinese, ample but purposeful whitespace, flat surfaces, small 4px radii, accessible contrast
Avoid: generic SaaS hero, centered everything, glassmorphism, gradients, beige, purple, floating cards, plants, desks, stock photography, fake metrics, decorative blobs, huge logo, illegible filler text, watermark
```

## B: Source to finished document

File: `homepage-concept-b-transformation.png`

```text
Use case: ui-mockup
Asset type: high-fidelity desktop website prototype, concept B
Primary request: Create a striking Chinese landing page for 浮现, a Markdown desktop reader. Direction B tells one clear transformation story: raw Markdown source becomes a beautifully finished document and then a shareable PDF. Make this cause-and-effect immediately understandable without explanatory marketing sections.
Input images: Image 1 is the official Fuxian mark; Image 2 and Image 3 are genuine app UI references and should stay visually accurate.
Composition/framing: 16:9 full website screenshot at desktop scale. Compact top navigation. Hero headline “从 Markdown，到成品文档” in the upper left. Across the main canvas, show three connected but unframed stages: a narrow monospaced Markdown source column, a large central real Fuxian application view, and two offset white A4 pages suggesting PDF output. Use thin cobalt connector lines and stage numbers 01, 02, 03. Keep the real app view the largest object. Show the beginning of a feature strip at the bottom.
Style/medium: premium product storytelling, editorial information design, crisp HTML/CSS-realistic interface, restrained motion cues implied by layout
Color palette: cool white, graphite, steel gray, cobalt blue, with a tiny coral accent from charts
Text (verbatim): “浮现”, “从 Markdown，到成品文档”, “源码”, “阅读”, “分享”, “免费下载”, “Windows · macOS”
Constraints: exact and readable Chinese typography, visible Markdown syntax, genuine app UI, logical left-to-right flow, 4px corner radii, high information clarity
Avoid: workflow diagram boxes, generic SaaS cards, gradients, dark theme, purple, beige, stock photography, desk scene, floating blobs, fake metrics, overly futuristic UI, watermark
```

Files: `homepage-concept-c-gallery.png`, `homepage-concept-c-gallery-v2.png`

```text
Use case: ui-mockup
Asset type: high-fidelity desktop website prototype, concept C
Primary request: Create a memorable Chinese landing page for 浮现, a Markdown desktop reader. Direction C is an immersive document gallery: the app interface itself is the hero and fills most of the first viewport. The brand should feel calm, exact, modern, and culturally distinctive.
Input images: Image 1 is the official Fuxian mark and must stay recognizable; Images 2 and 3 are genuine app views and must remain accurate.
```
