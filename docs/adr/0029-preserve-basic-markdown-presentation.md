# Preserve basic Markdown presentation and authored resources

CommonMark/GFM parsing is not sufficient when the application overrides table alignment or rejects ordinary image and email references. Preserve authored table alignment in the shared document theme; allow `mailto:` links through the existing click-only, known-document IPC path to the system mail application. This extends ADR 0028's external-link policy without enabling arbitrary application protocols.

HTTP(S) images, including extensionless endpoints and redirects, load through Chromium's image loader without a referrer. Local images still use the controlled `fuxian-resource:` protocol. References containing `../` travel as a query-encoded path so URL normalization cannot erase their meaning. The main process grants individual paths extracted from the actual source with the same Markdown/HTML parser, rather than granting an entire parent directory. Grants survive subsequent source revisions for pending reading/PDF snapshots. Referenced parent images participate in file watching like other local images. Absolute paths and arbitrary protocol URLs are not enabled by this decision. Paper/PDF image loading is cancellable and bounded to 15 seconds; failed or stalled images become explicit inline failures before pagination so later responses cannot alter finished pages.

Basic inert HTML includes `mark` and `u`. Inline `color` and `background-color` values are validated with CSSTree's CSS grammar before HTML sanitization; unrelated layout or resource-loading declarations remain excluded. Default highlight colors belong to document-theme tokens, while explicit author colors survive appearance changes. Reading, paper preview, and PDF share these rules. The `==highlight==` extension and reader-authored annotations are separate features, not added as part of CommonMark/GFM compatibility.
