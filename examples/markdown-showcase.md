# 天亮以前，去看海

周五晚上十点四十七分，阿遥发来一句：“明早去看日出吗？”我原本打算 ~~睡到自然醒~~，却在三分钟后回了一个字：**走**。我们在[地图](https://www.openstreetmap.org/)上选好东堤，把闹钟拨到 `04:20`，然后认真地期待起一个*还没有发生的清晨*。

> “天亮以前，海先学会了发光。”

## 出发之前

路上几乎没有车。便利店的灯亮得像一座小岛，我们买了两杯热咖啡，又在收银台前多拿了一包薄荷糖。

| 时间  | 地点       | 遇见的事           |
| :---- | :--------- | :----------------- |
| 04:34 | 城南便利店 | 咖啡、薄荷糖和晚风 |
| 05:16 | 东堤入口   | 潮声盖过了脚步声   |

### 包里只装三样东西

1. 一件能挡风的外套；
2. 一只装满热水的保温杯；
3. 一本不必写满的空白笔记本。

- 想带走的：一点海风，还有天空变亮的过程。
- 不必带走的：赶时间的习惯，以及昨天的坏心情。

> [!TIP] 看日出的小诀窍
> 不要一直盯着地平线。偶尔回头，身后的云也正在悄悄变色。

## 等太阳升起来

- [x] 查好潮汐和天气
- [ ] 记住这一刻，不急着发朋友圈

日出时间是 $T_s=05{:}36$，路程需要 42 分钟，再留 20 分钟给意外。最晚出发时间刚刚好：

$$
T_{depart}=T_s-42\text{ min}-20\text{ min}=04{:}34
$$

```yaml
alarm: '04:20'
coffee: double
destination: east-pier
```
