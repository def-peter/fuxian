# Fuxian Visual Capabilities

The parser and rendering tests are the source of truth. This matrix describes the current stable contract.

| Engine           | Accepted info string | Supported since | Execution                                     | Status                                                         |
| ---------------- | -------------------- | --------------- | --------------------------------------------- | -------------------------------------------------------------- |
| Mermaid          | `mermaid`            | Fuxian 0.1.0    | Local application runtime                     | Supported                                                      |
| PlantUML         | `plantuml`, `puml`   | Fuxian 0.1.0    | Configured PlantUML server                    | Supported                                                      |
| Vega-Lite        | `vega-lite`          | Fuxian 0.1.0    | Local isolated worker                         | Supported                                                      |
| AntV Infographic | `infographic`        | Fuxian 0.1.0    | Local isolated worker with reviewed resources | Supported                                                      |
| D2               | none                 | -               | -                                             | Unsupported; do not emit a `d2` block                          |
| Markmap          | none                 | -               | -                                             | Unsupported as document content; do not emit a `markmap` block |

Fuxian's article structure map is generated by the application from ordinary Markdown headings. It does not make `markmap` a recognized fence.

Prefer canonical `plantuml` in new content; `puml` remains a supported compatibility alias. No aliases are accepted for `vega-lite` or `infographic`.
